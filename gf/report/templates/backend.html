What is recorded per call

  • Request log: every tool call with arguments, response, HTTP status, start/end time, injected fault tag and any argument problems.
  • State before and after: orders, refunds and tickets, so "final state" expectations can be asserted.
  • Faults: a session can make the nth call to a tool slow, fail with a 500, time out or be rejected, to test honesty and recovery.
