Simulated caller

A second voice agent that plays the customer. It joins the same LiveKit room as the support agent and talks over real audio, so the agent hears exactly what a phone caller would sound like.

Brain

OpenAI model from the session, temperature 0 with a fixed seed. Prompted with the persona, the facts it may use and the goal. May only end the call through its end_call tool, with a summary and whether the goal was met.

Voice

Deepgram Aura-2 voice chosen per session (accent), pace, then the line conditions below applied to the outgoing audio. Hears the agent through Deepgram Nova-3.

Recorder

A hidden participant records a stereo file: left = caller as sent, right = agent as heard. All timing in reports is measured from this audio, not from events.

Validity rules

A call counts against the agent only when the simulation itself was sound. A call is invalid (excluded from pass rates, listed separately) when:
  • the caller spoke a number that is not in its facts, or talked about being an AI or a test (broke character);
  • the caller never spoke, or no agent record was written;
  • the runner hit an infrastructure error;
  • both sides were silent before the agent said anything.
An optional LLM persona judge (GF_PERSONA_JUDGE=1) gives an advisory opinion on character consistency; it never changes a verdict.

Reproducibility

Every parameter above lives in the session file and is hashed into the session id. The caller's LLM runs at temperature 0 with a seed, noise and packet loss are seeded, and the agent config hash is stamped on the record. Runs with the same stamp are comparable; the remaining variation is the agent's own LLM and live speech services.
