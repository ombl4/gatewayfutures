What passing looks like

  1. The simulation must be sound (caller in character, heard the agent correctly, no runner error), otherwise the call is invalid and does not count.
  2. The agent must do what this session asks, judged on the order system's log:
      {% for rq in p.requirements %}
    • {{ rq.text }}
      • {% endfor %}
  3. Every claim of a completed action must match a backend write.
  4. Hearing, latency, dead air, interruptions and speech quality are checked and can flag the call, never fail it.

A call passes when steps 1–3 hold. Each call's Grading tab shows these steps with its evidence.
